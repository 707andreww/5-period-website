# Sepak Takraw - Non-Traditional Games Unit

Seven-slide browser presentation by Andrew Taylor, with a game-video link on the final slide.
Open `index.html` in a browser. No build step is required.

## Slides

1. Sepak takraw
2. History and organizations
3. Equipment, sample budget/DIY, and facilities
4. Court measurements, kicking skills, and participation knowledge
5. Classroom rules, safety, and modifications
6. One-day lesson, with expandable quiz, answer key, evaluation, and teacher instructions
7. Game video, with expandable references and rubric coverage

The lesson assumes 39 students and 52 minutes, in 13 regus (teams) of three. Class rules,
game scoring, and budget allowances are identified as classroom adaptations.

## Presenting

Arrow keys, Space, and PageUp/PageDown navigate. Home/End jump to the first/last slide.
F toggles fullscreen. On-screen arrows, dots, and horizontal touch swipes also work.
Links use numbered hashes (`#6`). Print project expands the hidden sections for a complete
printable copy.

Preview the linked YouTube video and confirm classroom access before teaching.
Perform the live teacher demonstration described on slide 6.

## Sources and images
